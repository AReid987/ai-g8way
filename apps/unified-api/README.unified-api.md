## Overview

This Project solves a number of problems frequently encountered when working with LLMs and offers a few enhancements and conveniences:

### Features

**Singular Unified API Endpoint for all LLMs**

**Network Failure Tolerance**

**Diversification of LLMs**

**Streamlined Integration of LLMs**

**Prompt Caching**

**Intelligent Model Selection for a given task**

**Continuosly Improving Router Model with real time feedback**

**Load Balancers**

**Observability**

**Evaluations**

**Prompt Templates and Partials**
